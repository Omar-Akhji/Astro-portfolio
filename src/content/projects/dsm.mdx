# DSM.

Dashboard design layout (DSM) focusing on clean modularity, statistics tracking, and dark mode
readability.

## Key Features & Technologies

This project was developed utilizing the following core architecture and design tokens:

- **Figma** – Integrated as a key technological pillar.
- **UI Design** – Integrated as a key technological pillar.
- **Tailwind CSS** – Integrated as a key technological pillar.
- **Dashboard** – Integrated as a key technological pillar.

### Architectural Layout

Implementing a modern structural workflow:

1. **Responsive Shell**: Modular layout scaling flawlessly across various desktop/mobile screen
   sizes.
2. **Optimized Queries**: Direct data pipeline ensuring fast client response times and minimal
   layout shifts.
3. **Immersive Aesthetics**: Glassmorphism cards, HSL color tokens, and smooth entrance
   micro-animations.
